# Gauss name and icon

The name "Gauss" and the Gauss app icon (`Design/AppIcon-1024.png` and the copies in
`Gauss/Assets.xcassets`) identify the official app. They are **not** licensed under the GPL or
any other licence in this repository; all rights are reserved.

You're welcome to build and run Gauss from source for your own use. If you distribute a
modified version (a fork), please give it a different name and icon, so people can tell it
apart from the official Gauss.

Using the name to refer to Gauss (for example in a review, article or "works with
Gauss" note) is fine.

The icon is made from Christian Albrecht Jensen's 1840 portrait of Carl Friedrich Gauss, which
is in the public domain ([Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Carl_Friedrich_Gauss_1840_by_Jensen.jpg)).
The painting itself stays free for anyone to use; what's reserved is its use, cropped and
tinted as in `Design/make-icon.py`, as the icon of an app.
