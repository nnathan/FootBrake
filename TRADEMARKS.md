# FootBrake name and icon

The name "FootBrake" and the FootBrake icon (`Design/AppIcon.svg`, `Design/AppIcon-1024.png`
and `FootBrake/Assets.xcassets/AppIcon.appiconset`) identify the official app. They are
**not** licensed under the GPL or any other licence in this repository; all rights are
reserved.

You're welcome to build and run FootBrake from source for your own use. If you distribute a
modified version (a fork), please give it a different name and icon, so people can tell it
apart from the official FootBrake.

Using the name to refer to FootBrake (for example in a review, article or "works with
FootBrake" note) is fine.
